Format, kualitas, dan batasan yang perlu diketahui

JPG, PNG, dan WebP diproses dengan encoder browser. PNG tidak mempunyai kontrol kualitas lossy; target kecil mungkin memerlukan dimensi lebih kecil. Target diperlakukan sebagai batas ukuran, bukan janji byte persis. Jika target tidak tercapai, hasil diberi status Melebihi target. Konversi RAW kamera, HEIC, TIFF, dan PSD menggunakan ImageMagick WebAssembly yang dimuat dari CDN hanya saat diperlukan (sekitar 15 MB); dukungan tetap bergantung pada model kamera/codec. RAW diekspor sebagai gambar raster, bukan file RAW baru. File beranimasi atau berlapis diekspor menjadi satu gambar datar. Foto diproses lokal dan metadata tidak dipertahankan; warna dapat berbeda dari aplikasi RAW profesional. Pengurangan ekstrem, misalnya 30 MB menjadi 150 KB, bisa mengurangi dimensi dan detail. Jalankan melalui HTTPS atau localhost. Download kelompok mengirim unduhan gambar satu per satu secara otomatis. Browser mungkin meminta izin multiple downloads; aktifkan izin itu agar semua file dapat diterima. Lokasi file mengikuti pengaturan Downloads browser. Aplikasi tidak dapat memastikan setiap file selesai disimpan oleh browser. Tidak memakai database. Proses batch dilakukan bergantian untuk mengurangi penggunaan RAM.
